SMRITI JOSHI — CINEMATIC BIRTHDAY WEBSITE
==========================================

PROJECT FILES
- index.html: website content
- style.css: black cinematic / stardust styling
- script.js: animated stars, music controls, photo gallery and surprise interactions
- photos/: put Smriti's photos here
- music.mp3: your piano instrumental track goes here

RUN THE WEBSITE
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Open index.html in your browser, or install/use the Live Server extension.

ADD PIANO MUSIC
1. Choose a piano instrumental MP3 you have permission to use.
2. Rename it to music.mp3.
3. Place it in the same folder as index.html.
4. Open the website and click "Play piano".
Browsers block autoplay in many cases, so the visitor must click the music button.

ADD SMRITI'S PHOTOS
1. Open the photos folder.
2. Add up to three images and name them exactly:
   smriti-1.jpg
   smriti-2.jpg
   smriti-3.jpg
3. Refresh the page. The gallery supports click-to-expand photos.
You can use JPG, PNG or WebP, but if you use another extension, update the matching
src path in index.html (for example photos/smriti-1.webp).

CUSTOMIZE
The birthday message is in index.html inside .birthday-message.
The sign-off currently says "— Aashish".
The website uses Google Fonts when online and has fallback fonts for offline use.
